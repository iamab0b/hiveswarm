What this does

On first run it installs the Hiveswarm engine into ~/.hiveswarm/venv (inside WSL on Windows), writes a config with a demo project, and starts the decide service, the daemon, a worker and the app. After that, opening Hiveswarm is enough: the engine starts with it.
